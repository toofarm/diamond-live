# Game State

Live baseball scores, standings and individual player stats. 

Data sourced from [MLB public APIs](https://statsapi.mlb.com/api/v1), 

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Testing

Tests written using Cypress.io. To run the test suite, first run the app in development mode:

```bash
npm run dev
```

Then, in a separate terminal window, run the test suite:

```bash
npm run e2e
```

Open the Cypress user interface with the following:

```bash
npm run cy:open
```
